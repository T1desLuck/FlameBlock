## О проекте

FlameBlock — расширение для Chrome и Opera на Manifest V3, которое блокирует рекламу, трекеры и скрипты, требующие отключить блокировщик рекламы. Помимо этого в него встроены функции, которые обычно встречаются только в отдельных инструментах приватности — шум для защиты от отпечатка браузера (fingerprinting) и блокировка утечки реального IP через WebRTC.

Ключевой принцип проекта: **всё работает локально**. У расширения нет сервера, оно не отправляет и не собирает никакие данные — ни аналитику, ни статистику использования, ни содержимое страниц. Подробности — в [политике конфиденциальности](https://t1desluck.github.io/FlameBlock/privacy.html).

## Возможности

| Функция | Что делает | Статус |
|---|---|---|
| Блокировка рекламы | Сетевая фильтрация запросов к рекламным серверам через `declarativeNetRequest` | По умолчанию включено |
| Блокировка трекеров | Отключает счётчики и скрипты слежения за поведением | По умолчанию включено |
| Стелс-режим | Блокирует анти-adblock скрипты на сетевом уровне + гейт на `window.open` против попандеров и принудительных редиректов | По умолчанию включено |
| Косметическая фильтрация | Скрывает рекламные блоки по CSS-паттернам и текстовым меткам («Реклама», «Sponsored») | По умолчанию включено |
| Эвристика по размеру iframe | Ловит рекламу через собственный прокси-домен сайта по стандартным рекламным размерам фрейма | Экспериментально, выключено |
| Защита от отпечатка браузера | Детерминированный контролируемый шум в Canvas, WebGL, Audio и `measureText` | По умолчанию включено |
| Защита от утечки WebRTC | Скрывает реальный IP за VPN/прокси через `chrome.privacy` | Экспериментально, выключено |
| Свои правила | Свой список блокировки/разрешения — синтаксис в духе Adblock (`@@домен`, `!` — комментарий) | Доступно всегда |
| Разрешённые сайты | Точечное отключение защиты на конкретном сайте прямо из попапа | Доступно всегда |

Подробное описание того, как каждая функция реализована технически — в [технической документации](ARCHITECTURE.md).

## Приватность

- Расширение не собирает, не хранит и не передаёт никакие персональные данные.
- Нет аналитики, нет телеметрии, нет удалённого кода — весь JS находится внутри пакета расширения.
- Все настройки, счётчики и правила хранятся только в `chrome.storage` на устройстве пользователя.
- Полный текст политики: **[t1desluck.github.io/FlameBlock/privacy.html](https://t1desluck.github.io/FlameBlock/privacy.html)**

**Вручную, в режиме разработчика** (для тестирования локальной сборки):

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/T1desLuck/FlameBlock.git
   ```
2. Откройте `chrome://extensions` (в Opera — `opera://extensions`).
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и укажите папку проекта.

Минимальная поддерживаемая версия — Chrome 102 (см. `minimum_chrome_version` в `manifest.json`).

## Структура репозитория

```
FlameBlock/
├── manifest.json
├── background.js          # service worker: счётчики, DNR, синхронизация MAIN-world скриптов
├── common.js               # общие хелперы (настройки, форматирование, rule id)
├── content.js               # косметическая фильтрация (ISOLATED world)
├── fingerprint-protect.js  # защита от отпечатка браузера (MAIN world)
├── scriptlets.js            # стелс-режим / гейт на window.open (MAIN world)
├── popup/                   # интерфейс попапа
├── options/                  # страница настроек
├── rules/                    # статические DNR-списки (ads.json, trackers.json, antiadblock.json)
├── icons/
├── _locales/                 # переводы (12 языков)
├── index.html                # сайт проекта (GitHub Pages)
└── privacy.html               # политика конфиденциальности (GitHub Pages)
```
