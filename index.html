What it blocks

Eight layers of protection, all running on your machine

Most blockers stop at ads and trackers. FlameBlock adds the layers that usually only show up in paid privacy suites — fingerprinting noise, WebRTC leak protection, and a stealth mode built specifically to survive anti-adblock checks.

Ad blocking

Network-level filtering stops requests to known ad servers before they ever load, using the browser's own declarative request engine.

Tracker blocking

Cuts off the counters and behavior-tracking scripts that quietly follow you from site to site.

Stealth mode

Blocks known anti-adblock scripts at the network level and gates window.open to stop popunders and forced redirects. The list is updated as sites change tactics.

Cosmetic filtering

Hides ad slots by CSS pattern and by labels like "Advertisement" or "Sponsored" — even when there's no separate network request to catch.

iFrame size heuristic

Catches ads served through a site's own proxy domain — the kind standard filter lists never see — by spotting standard ad-sized frames from a foreign origin.

Experimental

Fingerprint protection

Adds quiet, controlled noise to Canvas, WebGL, audio and font measurements, so sites have a harder time recognizing your device — even without cookies.

WebRTC leak protection

Keeps your real IP address hidden behind a VPN or proxy. Off by default, since it can affect in-browser calls on sites that don't route through a proxy properly.

Experimental

Custom rules

Write your own list — one rule per line. A plain domain blocks it, @@domain allows it, and lines starting with ! are comments.

Getting started

Set up once, forget it's there

01

Install the extension

Add FlameBlock to Chrome or Opera. It's on by default the moment you install it — no setup required.

02

Adjust per site if you want

Toggle protection off for a specific site straight from the popup, or turn on the experimental layers if you want more.

03

Browse — that's it

FlameBlock runs quietly in the background, using the browser's own filtering engine instead of slowing pages down.
